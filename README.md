MB Web Monorepo

This monorepo contains a Mount & Blade-like web game with server, client, and shared packages.

Packages:
- packages/shared: shared types, constants, math, and protocol
- packages/server: authoritative simulation server (Express + WebSocket)
- packages/client: Vite + React + Phaser client with ECS

Quickstart:
- Install deps: npm install
- Dev: npm run dev
- Build: npm run build

Requires Node 18+.
